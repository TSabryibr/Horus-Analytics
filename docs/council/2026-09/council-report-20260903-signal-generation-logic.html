P1 Trickster Path Bypasses Manipulation Guard

check_buy_signal blocks pump-and-dump setups with (rel_vol > 5.0) AND (turnover < 4M). But check_trickster_signal has no such guard. A manipulated illiquid stock with artificially depressed RSI could trigger a false Trickster signal.

Fix: Add the manipulation check to check_trickster_signal before the core logic block.

P2 TP2 Fallback Uses Python Truthiness Instead of None Check

In _score_single_candidate line 571: target2 = sig.get('Target_Price_2') or sig['Target_Price'] * 1.04. If Target_Price_2 is 0.0 (falsy in Python), the fallback triggers even though 0.0 is a real value.

Fix: Change to sig.get('Target_Price_2') if sig.get('Target_Price_2') is not None else sig['Target_Price'] * 1.04

INFO Score Range Is Effectively 6–10, Not 0–10

Since breakout (+2) and is_liquid + volume_spike (+4) are preconditions, every signal starts at score 6 minimum. The BEARISH gate (Score >= 8) thus only requires 2 extra points, which is more permissive than the label suggests.

INFO EFI > 0 Gate May Be Redundant

When Move >= MOMENTUM (positive price change) AND Close > Res (breakout), EFI is almost always positive since it measures Close-to-Close delta * Volume. The gate adds marginal filtering power.
