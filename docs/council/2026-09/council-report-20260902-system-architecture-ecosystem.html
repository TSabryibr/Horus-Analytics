Detailed Advisor Submissions

1. The Contrarian — Siloed Tabs & The Analysis Paralysis Trap Expand ▾

When analytical features are split across 7 separate tabs, traders cherry-pick the single indicator that confirms their subconscious bias while ignoring opposing signals. Furthermore, if an operator holds 8 positions in Portfolio Manager, they get zero ambient warnings when a held stock appears in the Bull Trap detector.

The solution is not deleting tabs, but binding them with an automated Confluence Engine that cross-audits conflicting signals.

2. The First Principles Thinker — The Complete 5-Tier Decision Funnel Expand ▾

Institutional trading follows a strict hierarchical pyramid: (1) Macro Regime, (2) Sector Allocation, (3) Stock Selection, (4) Timing & Traps, and (5) Sizing & Rebalancing.

Horus already possesses the components for every tier. The task is establishing the vertical data pipeline so signals cascade seamlessly into execution.

3. The Expansionist — 5-Star Confluence Radar & Universal Dossiers Expand ▾

Introduce a 5-Star Confluence rating: Macro (Star 1), Sector RRG (Star 2), Seasonality (Star 3), Whale Flow (Star 4), and Technical Trigger (Star 5). Scale Kelly position sizing dynamically (1.0x to 1.5x) based on star rating.

4. The Outsider — Context-Aware Badges in Portfolio Rows Expand ▾

When inspecting my holdings in the Portfolio Manager, I shouldn't have to navigate to 4 other pages. Each position row should show pill badges: RRG: Leading, Whales: Accumulation, Traps: Clean.

5. The Executor — Concrete Integration Architecture Expand ▾

Leverage the existing GlobalDataContext and fast async APIs to build a unified confluence cache. Cross-link portfolio holdings with defensive alerts and setup promotion.
