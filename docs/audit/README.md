## Overview

The `docs/audit/` directory contains structured, progressive-disclosure audit pyramids produced by Hermes specialist swarms (`security-engineer`, `site-reliability-engineer`, `technical-architect`, and `qa-engineer`) across development and stabilization phases.

Each audit follows the 3-layer Artifact Pyramid architecture:
- **`00-index.md`:** Index and navigation affordances
- **`01-summary/`:** Executive summaries and verdict briefs
- **`02-analysis/`:** Technical domain analyses (security posture, site reliability, architecture, failure modes)
- **`03-dossiers/`:** Raw evidence ledgers, component inventories, vulnerability catalogs, and action matrices
